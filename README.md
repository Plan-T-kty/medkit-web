# 선교약품 — 웹 버전 (아이폰용)

의료선교 약품 재고·짐분배 앱의 설치형 웹 버전입니다. 안드로이드 앱(`medkit-ap`)과 같은 Google 시트에 연결됩니다.

- 팀 초대 링크: `https://plan-t-kty.github.io/medkit-web/?team=<Apps Script 웹 앱 주소>`
- 아이폰: Safari로 링크를 연 뒤 공유 버튼 → **홈 화면에 추가**
- 이 저장소의 파일은 `medkit-ap`의 `tools/build_web.py`가 만듭니다. 직접 고치지 말고 원본을 고친 뒤 다시 빌드하세요.
- GitHub Pages 설정: Settings → Pages → Source "Deploy from a branch" → Branch `main` / `/ (root)`. 이후 `main`에 푸시하면 자동으로 다시 게시됩니다.
